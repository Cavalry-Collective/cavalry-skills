# Visual Stack brand assets

Generated by `node scripts/generate-brand-assets.mjs`. PNGs need `sharp` on the module path; without it
the script writes the SVGs and skips rasterizing.

The mark is the [Cavalry](https://cavalry.sg) monolith cut into three slabs: same 64×64 block, same
margins, same red cut face at `x=46 w=12`, on the top slab.

## Colours

| Token | Hex | Usage |
|-------|-----|-------|
| Night | `#0a0810` | Dark backgrounds |
| Ink | `#f4eff5` | Mark body on dark |
| Red | `#ff3b30` | Cut face — do not recolour |

## Variants

PNG sizes: 256px, 512px, 1024px (suffix `-256.png`, `-512.png`, `-1024.png`).

| Stem | Use |
|------|-----|
| `vstack-mark-light` | Dark backgrounds — ink body, red cut face, transparent bg |
| `vstack-mark-dark` | Light backgrounds — night body, red cut face, transparent bg |
| `vstack-mark-mono-white` | Single colour on dark; top slab runs full width |
| `vstack-mark-mono-black` | Single colour on light; top slab runs full width |
| `vstack-mark-tile` | Avatar, README, tile — ink mark on a night square |

## Lockups (mark + wordmark)

Set in Space Mono Bold. PNG size 2240×440 (suffix `-1120.png`); the SVGs import the font, so open them
in a browser. Rendering the PNGs needs `playwright` and internet.

| Stem | Use |
|------|-----|
| `vstack-lockup-light` | Dark backgrounds, transparent bg |
| `vstack-lockup-dark` | Light backgrounds, transparent bg |
| `vstack-lockup-tile` | Documents and banners — works in either theme |

The skill UIs draw the same geometry inline as `.vsmark`, taking the body from `currentColor` and the
cut face from the page's brand variable, so it follows each tool's theme.

## Usage

- Clear space: one slab height on all sides.
- Do not recolour `#ff3b30`.
- Do not stretch — the viewBox is square.
